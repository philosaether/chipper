# Chipper

Plain-English editing interfaces for complex configuration.

Chipper lets users build structured data by clicking semantic chips arranged
in readable sentences — like writing a rule in English, but with the precision
of a form.

> Every **[2 weeks]** on **[tuesday]**, create a task named **[review accounts]** due **[end of day]**.

Early development. Architecture is defined, implementation is in progress.
